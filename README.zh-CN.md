# AI 个性化首页：中文版使用说明

这个浏览器新标签页插件基于 [ThariqS/ai-newtab](https://github.com/ThariqS/ai-newtab) 修改，保留上游 MIT 许可证和原作者署名。

**默认简体中文**。首次安装后的模型配置、按钮、设置、生成进度、错误提示均显示中文，模型生成的页面也默认采用中文。可在初次连接页面或「设置 → 界面与首页语言」切换到 English 或 日本語。更改语言并保存后，新生成的首页会使用所选语言；之前保存的页面仍保留原语言，直到重新生成成功。

## 一、下载安装

**方式 A：无需开发环境。** 在 [GitHub Actions](https://github.com/siskosun/ai-newtab/actions/workflows/build.yml) 打开最新一次成功的 `Build and test`，下载 `ai-newtab-chrome-mv3` 构建产物并解压。构建产物一般需要登录 GitHub 才能下载，保存期为 14 天。加载解压后含有 `manifest.json` 的文件夹。

**方式 B：自行编译。** 环境：Chrome 或 Edge、Node.js 20 或以上版本。

```bash
git clone https://github.com/siskosun/ai-newtab.git
cd ai-newtab
npx pnpm@10.11.1 install
npx pnpm@10.11.1 build
```

打开 `chrome://extensions`（Edge 可使用 `edge://extensions`），启用开发者模式，点击「加载已解压的扩展程序」，选择仓库的 `apps/extension/.output/chrome-mv3` 文件夹。随后打开一个新标签页。

## 二、配置模型并生成首页

首次使用选择 OpenAI、Gemini、Claude、DeepSeek、Qwen 或 OpenAI 兼容接口，填写服务商提供的 **实际模型 ID** 及 API 密钥。使用本机兼容服务时，可填写完整接口地址，例如 `http://localhost:11434/v1/chat/completions`，该场景允许空密钥（具体仍取决于本机服务配置）。

点击「保存配置」，再点击「生成今日首页」。之后可在「设置」中更改模型、密钥、语言、生成偏好和禁止访问的域名。保存设置会发起一次新生成；生成失败时原有首页会保留。

## 三、主动订阅网站 + 浏览兴趣

打开「设置」，在「主动订阅的网站」中每行填写一个网站，例如：

```text
news.ycombinator.com
https://example.com/technology
```

- **最多订阅 4 个网站**：优先读取你指定的网址或栏目路径；剩余名额由过去 14 天的浏览历史补充，整次生成**最多打开 8 个网站**。
- 同一域名只读取一个网址，避免订阅栏目与历史站点重复采集；未设置订阅时保持原本的纯浏览历史行为。若没有浏览历史，也能从你指定的网站生成内容。
- 自动补齐缺失的 `https://` 前缀，移除网址的查询参数与 `#` 片段，避免将可能含有令牌的地址保存到配置中；主动订阅中**禁止**邮箱、在线文档、登录页面、内网地址及「禁止读取的网站」列表中的域名。
- 本功能读取网站页面，而不是专业 RSS 阅读器，不保证能解析 RSS XML、需要登录的网站或反爬页面。网站列表仅保存在浏览器本地。实际读取的网页内容仍会送往你选定的模型服务商。
- 生成完成后，点击「读取来源」可查看每个成功读取的页面是来自「主动订阅」还是「浏览兴趣」。来源列表只记录读取事实，不保证报道真实或即时。

本次改造继续保留单次模型生成、自动更新和失败时的旧首页，不需要服务器和额外 API 账单。

## 四、中文内容生成

AI 会把已选网页的英文及其他语言内容概括为自然简体中文，保留专有名词和原始文章链接，不应额外编造来源。实际效果取决于所选模型的语言能力、网页可访问性和页面内容。它不会翻译原网页，也不会把已有缓存首页即时翻译成中文。

已读网页最多 8 个；数据源可来自主动订阅和浏览历史。如果首次生成内容少，检查浏览器已有的常访问站点、网页访问权限及「禁止读取的网站」设置。

## 五、信息来源与去重（借鉴 AIHOT）

借鉴 [AIHOT](https://github.com/KKKKhazix/AIHOT) 的“来源可追溯、相同事件只呈现一次、旧信息不冒充最新”原则。每次成功生成后，首页右上角会出现「读取来源」，列出**这次实际打开过的网页**和读取时间（会去掉网址中的查询参数等可能包含隐私的部分）。失败或被阻止的网页不会出现在来源清单中。

这份清单**只证明程序读取了哪些网页，不证明生成的每句话正确，也不证明链接文章在何时发布**。模型收到的采集时间明确标记为“读取时间”；没有可靠发布时间，不允许称为“刚刚发布”“今日新消息”。模型会尽量合并同一事件的多家报道，并保留原文链接；这是提示词约束，实际去重与事实一致性仍需实测验证。

本次借鉴**没有**复制 AIHOT 的采集、评分、数据库、后台或事件归组代码，不需要 Docker 和服务器。已有缓存的旧首页不含来源清单，重新生成后才会出现。

## 六、增量自动更新：内容不变时省略模型调用

默认开启「设置 → 智能增量更新」，**仅作用于自动更新**。自动更新仍会按原有计划读取网页；检查通过且网页内容、关注的来源和生成配置均未发生可观察的变化时，直接复用上次成功生成的首页，不调用模型。页面会显示「已检查，内容无变化；本次未调用模型」，同时保留原首页的生成时间和来源记录。

**手动点击「重新生成」或「保存并重新生成」始终调用模型**，不受此开关影响。想关闭省额度功能，可在设置中取消勾选。

增量缓存的安全边界：
- 首次运行、旧版首页没有指纹、网页读取失败或不完整、订阅网站/所选历史网站变化、网页标题/正文/链接变化、提示词、语言、模型、接口、禁止网站变化时，正常重新生成。
- 日期跨天或成功生成后的缓存满 **24 小时**时，即便正文一样也会重新生成，避免“今日”之类描述长期过期。
- 只在成功生成后保存 SHA-256 内容指纹；**不会为增量功能另外存储网页正文、历史记录或 API 密钥**。模型调用失败不能改写成功首页的指纹。
- 网站中的广告、计数器、动态时间文本也可能让指纹变化，导致模型仍被调用。因此这是一项保守的节省调用功能，**不是新闻时效性验证，也不保证每次自动更新都省费**。
- 自动检查需要继续读取网页，会产生常规的网页访问流量；它不会产生模型请求，但不等于完全没有资源成本。

## 七、测试

```bash
npx pnpm@10.11.1 typecheck
npx pnpm@10.11.1 test
npx pnpm@10.11.1 build
```

自动化检查不消耗真实模型额度。实际模型接入、中文摘要质量和浏览器显示效果还需要使用自己的 API 密钥验证。

## 八、隐私

浏览历史摘要、网页正文摘录和自定义指令会发送给你选择的模型服务商，部分网页可能包含登录后的私人信息。**请先配置禁止访问的网站**，并了解对应服务商的数据留存政策。密钥仅存储在当前浏览器配置的 `chrome.storage.local` 中，拥有对应配置访问权限的人或程序可能读取它。此版本仅建议自行使用，不应直接携带用户 API 密钥公开上架扩展商店。
